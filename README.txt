NordMatch v6

Kurulum:
npm install
npm start
http://localhost:3000

V6 yenilikleri:
- Admin paneli
- Güvenlik: Helmet, rate limit, daha güçlü şifre hash'i, input temizleme
- Demo e-posta doğrulama
- Demo şifre sıfırlama
- Jeton mağazası: 50 / 150 / 400 / 1000 jeton
- Jeton işlem geçmişi
- Gelişmiş keşfet: yaş, şehir, cinsiyet, doğrulanmış profil, çevrimiçi, sıralama
- Bildirimler: beğeni, eşleşme, mesaj, doğrulama
- Mesajlarda okundu bilgisi YOK
- Admin: kullanıcı, şikâyet, doğrulama, istatistikler

Demo admin:
Kayıt olurken e-posta olarak admin@nordmatch.local kullan.
Şifreyi sen belirlersin (en az 8 karakter).

Not:
- Jeton satın alma şu an DEMO'dur, gerçek karttan para çekmez.
- E-posta doğrulama ve şifre sıfırlama kodu/tokenı demo olarak ekranda gösterilir.
- Yayına çıkmadan önce gerçek e-posta servisi, gerçek ödeme sağlayıcısı, üretim veritabanı ve kalıcı dosya depolama gerekir.
